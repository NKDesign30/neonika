# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help.

## What that means here

Criticise code, not people. "This leaks a token on line 40" is useful.
"This is amateur work" is not.

Harassment, personal attacks, and discrimination of any kind are not welcome —
in issues, pull requests, commit messages, or anywhere else this project touches.

If you are wrong, say so and move on. Nobody here has been doing this long
enough to stop being wrong sometimes.

## Enforcement

Report problems to **info@design-nk.de**. Reports are handled privately.

The maintainer may edit, hide, or delete comments, and may block accounts, for
behaviour that violates this document. There is no appeals committee — this is a
small project.

## Scope

This applies in project spaces and when representing the project elsewhere.
